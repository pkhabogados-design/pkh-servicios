📥 Importar datos

CÓMO IMPORTAR — PASO A PASO
1
Obtené el archivo — exportá el backup desde este sistema (Exportar datos) o recibí el archivo JSON de otro usuario del sistema.
2
Elegí el modo — Fusionar si querés agregar datos nuevos sin perder los actuales. Reemplazar solo si querés cargar todo desde cero.
3
Seleccioná el archivo — hacé clic en el botón, elegí el archivo .json y verificá el resumen que aparece.
4
Confirmá — revisá el resumen y presioná el botón de confirmación. El sistema se actualizará automáticamente.

El archivo debe ser un JSON exportado desde este sistema (extensión .json).
